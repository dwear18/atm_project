# Симуляция банкомата (ATM Simulator)

Учебный проект (2 курс, КубГУ).

Программа имитирует работу банкомата с графическим интерфейсом на **tkinter**: пользователь проходит аутентификацию по номеру карты и PIN-коду, после чего может выполнять основные банковские операции.

---

## Возможности программы

* Авторизация по номеру карты и PIN-коду.
* Проверка текущего баланса.
* Снятие наличных с проверкой остатка и лимита (до 100 000 ₽ за одну операцию).
* Внесение наличных.
* Перевод средств между счетами.
* Просмотр истории операций.
* Завершение пользовательского сеанса.

### Дополнительные функции

* PIN-код хранится в виде SHA-256 хеша.
* Карта блокируется после трёх неверных попыток ввода PIN.
* Все операции автоматически сохраняются в файл истории.

## Файлы данных

### `accounts.json`

Хранит информацию о банковских счетах:

* номер карты;
* хеш PIN-кода;
* имя владельца;
* баланс;
* состояние блокировки карты.

### `transactions.json`

Хранит историю всех выполненных операций с указанием типа операции, суммы, даты и номера карты.

---

## Реализованные классы

* **Account** — модель банковского счёта.
* **ATM** — бизнес-логика банкомата (авторизация, операции, проверки).
* **ATMApp** — графический интерфейс приложения.
* **Storage** — загрузка и сохранение данных в JSON.
