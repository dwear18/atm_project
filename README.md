# Симуляция банкомата

Учебный проект: настольное приложение на Python + tkinter, имитирующее
работу банкомата.

## Запуск

```bash
python main.py
```

Требуется Python 3.9+ (tkinter входит в стандартную библиотеку).

Тестовые карты (accounts.json):

| Номер карты           | PIN  | Владелец       | Баланс   |
|------------------------|------|----------------|----------|
| 1234-5678-9012-3456    | 1234 | Иванов Иван    | 50 000 ₽ |
| 9876-5432-1098-7654    | 4321 | Петрова Мария  | 15 000 ₽ |

## Структура проекта

```
atm_project/
├── main.py                # точка входа
├── accounts.json          # данные клиентов (создаётся заново при необходимости)
├── transactions.json      # журнал операций
└── atm/
    ├── constants.py        # лимиты и номиналы купюр
    ├── models.py            # класс Account
    ├── storage.py            # чтение/запись JSON
    ├── atm_core.py            # класс ATM — бизнес-логика
    └── gui.py                 # класс ATMApp — интерфейс tkinter
```

## Реализованные требования ТЗ

- Авторизация по номеру карты и PIN-коду.
- Проверка баланса.
- Снятие наличных: сумма от 100 до 100 000 ₽, кратная 5, с проверкой
  достаточности средств и разбором на купюры (5, 10, 100, 200, 500,
  1000, 5000 ₽).
- Пополнение счёта.
- Перевод на другой счёт (с проверками: карта существует, средств
  достаточно, нельзя переводить самому себе).
- История операций (дата/время, тип, сумма, описание).
- Завершение сеанса — возврат на экран входа.
- Данные хранятся в accounts.json / transactions.json и сохраняются
  между запусками.
- PIN хранится в виде SHA-256 хеша (hashlib), а не в открытом виде.
- Блокировка карты после 3 неверных попыток ввода PIN подряд.
- Обработка ошибочного ввода и повреждённых/отсутствующих JSON-файлов
  с понятными сообщениями пользователю.

## Как сгенерировать/сбросить тестовые данные

```bash
python3 -c "
import hashlib, json

def h(pin):
    return hashlib.sha256(pin.encode('utf-8')).hexdigest()

accounts = [
    {'card_number': '1234-5678-9012-3456', 'pin_hash': h('1234'),
     'holder_name': 'Иванов Иван', 'balance': 50000.0,
     'failed_attempts': 0, 'locked': False},
    {'card_number': '9876-5432-1098-7654', 'pin_hash': h('4321'),
     'holder_name': 'Петрова Мария', 'balance': 15000.0,
     'failed_attempts': 0, 'locked': False},
]
json.dump(accounts, open('accounts.json', 'w', encoding='utf-8'), ensure_ascii=False, indent=2)
json.dump([], open('transactions.json', 'w', encoding='utf-8'), ensure_ascii=False, indent=2)
"
```
