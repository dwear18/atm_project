# Симуляция банкомата (ATM Simulator)

Учебный проект по теме **2.9 «Симуляция банкомата»** в рамках учебной практики КубГУ.

Программа имитирует работу банкомата с графическим интерфейсом на **Python и tkinter**.

## Возможности

После авторизации по номеру карты и PIN-коду пользователь может:

* проверить баланс;
* снять наличные;
* внести наличные;
* перевести средства на другой счёт;
* посмотреть историю операций;
* завершить сеанс.

### Дополнительные возможности

* PIN-код хранится в виде SHA-256 хеша;
* карта блокируется после трёх неверных попыток ввода PIN;
* операции автоматически сохраняются в `transactions.json`;
* для снятия наличных установлен лимит **100 000 ₽ за одну операцию**.

## Используемые технологии

* **Python 3.9+**
* **tkinter** — графический интерфейс;
* **JSON** — хранение данных;
* **hashlib** — хеширование PIN-кодов;
* **dataclasses** — описание модели счёта.

## Запуск

1. Установить Python 3.9 или новее.
2. Перейти в папку проекта.
3. Запустить программу:

```bash
python main.py
```

## Файлы данных

### `accounts.json`

Содержит данные банковских счетов:

* номер карты;
* хеш PIN-кода;
* имя владельца;
* баланс;
* состояние блокировки карты.

### `transactions.json`

Содержит историю выполненных операций:

* тип операции;
* сумма;
* дата и время;
* номер карты.

## Основные классы

* **Account** — модель банковского счёта.
* **ATM** — основная логика банкомата и банковских операций.
* **ATMApp** — графический интерфейс приложения.
